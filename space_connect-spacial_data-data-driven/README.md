## 📋 Sobre o Projeto

[cite_start]Sistema responsável por registrar eventos detectados (como desmatamento, queimadas, variações climáticas ou uso do solo), incluindo informações geográficas e métricas associadas a cada ocorrência. O objetivo é simular um cenário real onde múltiplos registros precisam ser armazenados, analisados e convertidos em informações estratégicas.
